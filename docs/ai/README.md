# 给 AI 的任务入口

先读 [AGENTS.md](../../AGENTS.md) 和 [平台状态](../platforms/README.md)。选择一个任务，把已知环境、要验证的方向和目标范围交给 AI。

## 从头部署

> 在我的本机按 `docs/LOCAL_SETUP.md` 第 1–3 节部署。使用测试数据库、空白 vault 和独立 SQLite 索引。凭据由我在本机填入。先跑 `--check`，再同步两次，核对首轮 Markdown 里的原句、正文、链接和第二轮无变化的结果。在测试环境验收后汇报。

## 检查环境或同步问题

> 先按 `docs/deployment/README.md` 确认主机架构、Python 环境、可用空间、目标目录和配置来源。只报告配置项是否存在，不显示值。区分目录、权限、网络、字段映射和 Markdown 输出问题，说明已检查的项目、报错和下一步。

## 整理历史笔记

> 先读 `docs/platforms/README.md` 的印象笔记章节。对我指定的 ENEX 样例列出可保留的字段、附件、来源与重复风险，再给出整理方案。用样例验证后再确定正式收录的范围。

汇报时把代码测试、模拟 API 和真实平台的验证分开。只使用已经确认的数据源、目标目录和同步方向。
